Scenario analysis and risk auditing terminal (Turtle Terminal) for Derivatives. Few strategies worked on Stat-arb, Vol-Arb, Turtle Strategy, and Smart Money. Sentiment Analysis, Regime Analysis, Risk models like VaR, ES, Principal Component Analysis to name a few.

This system is designed to:
- Analyze derivatives markets using OI, volume, volatility, and positioning data
- Infer market state and sentiment from derivative-specific indicators
- Quantify risk using scenario analysis and VaR-style measures
- Propose trade ideas with explicit risk–reward under different scenarios
