* **Data Parsing:** `india_vix` and `pe_ratio_idx` share the exact same NSE source file (`ind_close_all`). The generic `FieldMapper` will default to `pe_ratio_idx`, meaning `india_vix` requires an explicit override (e.g., in `backend/ingest/nse_importer.py`) to map correctly.
* **NSE API Dates:** Some NSE endpoints for equities data (like PE Ratio at `/content/equities/peDetail/PE_{ddmmyy}.csv`) expect a 2-digit year format (`%d%m%y`). However, it is always a best practice to provide a fallback to the old 4-digit archive URL (`%d%m%Y`) in case the endpoint fails.
* **UI Components:** The "Import Data" tab layout uses a side-by-side flex layout (`.import-container`, `.import-left-panel`, `.import-right-panel`) to display the import controls next to mock terminal logs (Uvicorn and Celery).
* **Celery Logs:** Since Celery workers run synchronously and do not have an ASGI event loop, they cannot broadcast logs via WebSockets directly. Instead, Celery logs must be polled from the `/api/audit/history` API endpoint in the frontend (e.g., in `workbench.html`).
* **State Persistence:** Background task IDs (like Celery import tasks) should be persisted in `localStorage` (e.g., `activeImportTaskId`) in the frontend so that the progress bar and polling logic can resume seamlessly if the user refreshes the browser page.
