# Turtle Terminal: Project Analysis

## 1. Architecture Overview
Turtle Terminal adheres to a **"Disconnected Intelligence"** architecture, ensuring strict separation between data, logic, and reasoning.

-   **The Brain (Local)**: A Python 3.11+ backend running on FastAPI. It houses the deterministic analytical engines (`backend/analysis`, `backend/risk`) that compute indicators, Greeks, and risk metrics. It is the "Single Source of Truth".
-   **The Reasoner (Cloud/Local API)**: The AI (Turtle/Gemini) acts purely as an Orchestrator and Explainer. It translates user natural language into Python code, which is then executed safely by the local brain. It **never** sees raw data, only summarized outputs.
-   **The Database**: PostgreSQL (for persistence) + TimescaleDB (for high-speed market data) is the system of record.
-   **The Shell (Frontend)**: A React-style web interface (served via Jinja2 templates currently) providing a persistent "Analysis Workbench" with a global navigation shell.

## 2. UI Components (The "Analysis Workbench")
The UI follows a **Shell Architecture** to support "forever enhancements".

-   **Global Navigation Shell**:
    -   **Sidebar**: Persistent access to modules:
        -   📊 **Workbench**: The main dashboard.
        -   🔍 **Market Scan Hub**: Trade discovery.
        -   🛡️ **Risk Analytics Center**: Deep-dive stress testing.
        -   📥 **Data Vault**: Ingestion hub.
    -   **Global Header**: Context-aware toolbar for "Save Layout", "Export PDF", "Download CSV".
-   **Widgets Registry**:
    -   **Vol Surface**: 3D mesh visualization of Implied Volatility.
    -   **Statistical Distribution**: Bell curves for PnL probability and "Fat Tail" analysis.
    -   **Greeks Matrix**: High-density table for Delta/Gamma/Vega/Theta.
    -   **Market Scanner**: Card-based view of high-conviction trade setups.
-   **Jules/Turtle Sidebar**:
    -   **Chat Interface**: Terminal-style input for querying the system.
    -   **Risk Panel**: A mandatory "Red Box" highlighting the Worst-Case Scenario for every active context.
    -   **Code Audit**: Toggle to view the exact Python code generated by the AI.

## 3. Core Modules & Engines

### 🛡️ Risk Engine (`backend/risk`)
-   **Purpose**: Quantify downside before opportunity.
-   **Key Components**:
    -   `evaluate_scenario`: Calculates PnL under shocks (e.g., -10% Spot, +20% Vol).
    -   `standard_scenarios`: Pre-defined stress tests (Gap Down, Vol Spike).
    -   `Greeks Engine`: Computes sensitivities (Delta, Gamma, Vega).

### 📐 Strategy Builder (`backend/strategies`)
-   **Purpose**: Define and execute trading logic.
-   **Key Components**:
    -   `StrategyEngine`: Registry and execution loop for strategies.
    -   `BaseStrategy`: Abstract Blueprint ensuring all strategies implement `compute_indicators` and `check_signals`.
    -   `TurtleSystem1`: Reference implementation of the classic breakout strategy.

### 🧪 Backtester (`backend/backtest`)
-   **Purpose**: Validate logic against history.
-   **Key Components**:
    -   `BacktestEngine`: "Time machine" that replays historical data against strategy logic.
    -   `Performance Metrics`: deterministic calculation of CAGR, Drawdown, and Win Rate.

### 🤖 AI Chat Orchestrator (`backend/orchestration`)
-   **Purpose**: Bridge natural language to code.
-   **Key Components**:
    -   `Executor`: Manages the loop: Query -> Gemini -> Code -> Sanitize -> Execute -> Audit.
    -   `Sanitizer`: Whitelists allowed modules to prevent unsafe code execution.
    -   `MarketOrchestrator`: specialized pipeline for running multi-point scanners (PCR, IVR, Flow) in parallel.

### 🔍 Market Scanner (`backend/analysis/scanners`)
-   **Purpose**: Find anomalies.
-   **Key Components**:
    -   `PCR Mean Reversion`: Detects sentiment extremes.
    -   `IV Rank/Percentile`: Identifies cheap/expensive volatility.
    -   `Institutional Footprint`: Flags large volume spikes (Smart Money).

## 4. Detailed Features List

-   **Deterministic Logic**: No AI hallucinations. All numbers come from `numpy`/`pandas`.
-   **Multi-Point Scanning**: Combines Sentiment (PCR), Volatility (IVR), and Flow (Large Orders) into a single "Trade Card".
-   **Scenario Stress Testing**: Instant PnL simulation for customizable shocks (Price/Vol).
-   **Historical Backtesting**: Validate custom formulas against past market regimes.
-   **Rich Reporting**: One-click generation of PDF/HTML reports with the "Story behind the Trade".
-   **Persistent Dashboards**: Save custom layouts (JSONB) to the database.
-   **Data Ingestion**: Drag-and-drop CSV upload + Live Upstox API integration.
-   **Audit Trail**: Every AI action and Trade Idea is logged with a user ID and timestamp.
-   **On-Prem Licensing**: Hardware-bound execution for secure distribution.
